# 🎹 Project DIVA Dreamy Mix v1.1

Добро пожаловать в фанатский ритм-движок, созданный Артуром!

## 🕹️ Управление
Игра поддерживает управление двумя руками для максимального спама кнопками:
*   **Левая рука:** W, A, S, D
*   **Правая рука:** I, J, K, L
*   *(Полная поддержка геймпадов через маппинг в TurboWarp/PenguinMod)*

## 🛠️ Особенности версии
*   Графика и текстуры в стиле MegaMix.
*   Встроенная интерактивная система проверки PSP-сейвов (Bypass PSP check).
*   Идеальный отклик кнопок без багов стандартного Scratch.
*   Всего 2 трека на старте (как во Future Tone Prelude), но движок готов к добавлению новых модов!
